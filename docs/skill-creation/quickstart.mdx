在本教程中，你将创建一个技能，让智能体能够使用随机数生成器来掷骰子。

## 前置条件

- [VS Code](https://code.visualstudio.com/) 并安装 [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)

<Note>
本教程使用 VS Code，但 Agent Skills 是一种开放格式。同样的技能可以在任何兼容的智能体中使用，包括 Claude Code 和 OpenAI Codex。
</Note>

## 创建技能

技能是一个包含 `SKILL.md` 文件的文件夹。VS Code 默认在 `.agents/skills/` 目录下查找技能。在你的项目中创建 `.agents/skills/roll-dice/SKILL.md`：

````markdown .agents/skills/roll-dice/SKILL.md
---
name: roll-dice
description: 使用随机数生成器掷骰子。当被要求掷骰子（d6、d20 等）、掷骰或生成随机骰子结果时使用。
---

要掷一颗骰子，请使用以下命令生成从 1 到指定面数的随机数：

```bash
echo $((RANDOM % <sides> + 1))
```

```powershell
Get-Random -Minimum 1 -Maximum (<sides> + 1)
```

将 `<sides>` 替换为骰子的面数（例如，标准六面骰为 6，d20 为 20）。
````

就这样——一个文件，不到 20 行。以下是各部分的作用：

- **`name`** — 技能的简短标识符。必须与文件夹名称匹配。
- **`description`** — 告诉智能体何时使用此技能。这是智能体决定是否激活该技能的主要依据。
- **正文内容** — 技能激活时智能体遵循的指令。在这里，智能体被指示运行终端命令。

## 试试看

1. 在 VS Code 中打开你的项目。
2. 打开 Copilot Chat 面板。
3. 从聊天面板底部的模式下拉菜单中选择 **Agent（智能体）** 模式。
4. 输入 `/skills` 确认 `roll-dice` 出现在列表中。如果没有出现，请检查文件是否保存在 `.agents/skills/roll-dice/SKILL.md`。
5. 提问：**"掷一个 d20"**

智能体应该会激活 `roll-dice` 技能。它可能会请求权限来运行终端命令。

<Note>
工具使用的可靠性因模型而异——有些模型会始终遵循技能指令并一致地运行命令，而有些模型则可能不稳定。
</Note>

## 工作原理

以下是幕后发生的事情：

1. **发现（Discovery）** — 当聊天会话开始时，智能体扫描默认技能目录并列出可用技能。
2. **激活（Activation）** — 当你询问关于掷骰子的问题时，智能体将你的问题与 `roll-dice` 的描述进行匹配，确定该技能相关，并将其加载到上下文中。
3. **执行（Execution）** — 智能体按照技能正文中的指令，构造并运行正确的 shell 命令来掷骰子。
